# 轻盈计划 · 手机适配网站

纯 HTML、CSS 和 JavaScript 的响应式单页网站，不依赖前端框架或后端。身高、体重、体脂率、计划和每周打卡都保存在当前浏览器；网站不会将这些资料上传到云端。

## 打开方式

直接打开 `index.html`，或用任意静态文件服务器预览。部署时可发布到 GitHub Pages 等静态托管服务。静态托管只提供网页文件，不接收计划资料。

## 当前功能

- 输入身高、体重及选填体脂率。
- 选择每天可运动 20、30、45、60 或 90 分钟，周期为 1–6 个月。
- 生成 BMI 参考、每周训练安排、逐月进阶、饮食习惯提示和每周复盘建议。
- 根据本机日期和星期突出显示今日安排；勾选完成后今日卡片与周计划同步变灰。
- 本周打卡进度条、周一自动重置；手机端固定底部导航和加大触控区域；支持打印/另存为 PDF。
- 可生成 6 位本机码，把计划资料保存在当前浏览器；下次打开时可自动恢复，也可输入本机码恢复。
- 支持导出 JSON 备份文件，在另一台设备手动导入；不需要注册或云端数据库。
- 可保存、删除本机资料；成人确认、低 BMI 提示和基本输入范围校验。

## 本机存储与备份

资料仅保存在浏览器的本地存储中，不会由页面上传。6 位本机码只是同一浏览器、同一网站地址下查找资料的编号，不是加密密码；它不能单独在其他设备恢复资料。清理浏览器数据、更换浏览器或更换网站地址可能会让本机资料不可用。

跨设备使用时，请先在原设备导出备份 JSON，再通过自己选择的方式传给另一台设备并导入。备份文件包含 6 位码、身高、体重、体脂率和计划选项等个人资料，请妥善保管并在不需要时自行删除。删除页面中的本机资料不会删除已下载的备份文件。

## 健康说明

面向成年人的一般健康信息原型，不是诊断或医疗建议。BMI 低于 18.5 时不建议设置减脂目标。活动建议参考成人每周至少 150 分钟中等强度有氧活动和每周 2 天力量活动；基础信息不足以安全地计算个人热量目标，因此页面不生成热量处方或预测减重数字。
